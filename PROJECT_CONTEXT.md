# Contexto del Proyecto: MercaTodo

## 1. Descripción General y Contexto del Negocio

> **Contexto Principal:**
> El administrador de **MercaTodo** necesita un sistema que le permita realizar la venta de sus productos de mercadería online. El sistema deberá permitir registrar cada producto así como también administrar las cuentas de sus clientes, quienes también deberán identificarse para realizar compras de los artículos de mercadería.
> 
> Para el administrador de MercaTodo es sumamente importante que el sistema permita realizar pagos online y generar reportes que permitan tomar decisiones.
> 
> También es indispensable que el sistema permita administrar productos de manera masiva.
